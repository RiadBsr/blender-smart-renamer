# Smart Renamer AI

## Overview
Smart Renamer AI is a Blender addon that leverages AI to intelligently rename objects in your Blender projects. By analyzing the selected object and using advanced image recognition, it provides meaningful names based on the object's characteristics.

## Features
- AI-powered renaming of Blender objects.
- User-friendly interface integrated into the Blender sidebar.
- Option to take isolated screenshots of objects for analysis.
- Customizable naming styles and options.

## Installation
1. Download the `smart-renamer-ai` folder.
2. Open Blender and go to `Edit` > `Preferences`.
3. In the Preferences window, navigate to the `Add-ons` tab.
4. Click on `Install...` and select the `smart-renamer-ai` folder.
5. Enable the addon by checking the box next to "Smart Renamer AI".

## Usage
1. Select the object you want to rename in your Blender scene.
2. Open the Smart Renamer AI panel from the sidebar (press `N` to toggle the sidebar).
3. Enter your API key in the designated field.
4. Choose your preferred naming style from the dropdown menu.
5. Click the "Analyze & Rename" button to initiate the renaming process.
6. The addon will take a screenshot of the selected object, send it to the AI for analysis, and rename the object based on the response.

## API Key
To use the Smart Renamer AI, you will need an API key from the Google Gemini API. Please ensure you have access to the API and have obtained your key before using the addon.
